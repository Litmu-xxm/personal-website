# Personal Website — Xiao Mu (小小穆)

Three versions of a single-page personal website built for COMP5583
(Agentic Computing, Systems, and Applications).

| Version | Technique | URL |
|---|---|---|
| V0 | Baseline (zero-shot) | https://litmu-xxm.github.io/personal-website/V0/ |
| V1 | In-context learning (few-shot) | https://litmu-xxm.github.io/personal-website/V1/ |
| V2 | Retrieval-augmented generation (RAG) | https://litmu-xxm.github.io/personal-website/V2/ |

## How to open
Each version is a fully self-contained static site (vanilla HTML/CSS/JS).
Open `V0/index.html`, `V1/index.html`, or `V2/index.html` directly in a
browser, or visit the deployed URLs above. No build step, dependencies,
or backend are required.
